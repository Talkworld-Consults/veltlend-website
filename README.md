# VeltLend Final Prelaunch Landing Page

This package contains the approved VeltLend landing page plus the four prelaunch legal pages:

* Privacy Policy
* Terms of Use
* Refund & Cancellation Policy
* Cookie Policy

The landing page points to the production waitlist API:

https://veltlend-waitlist-api.onrender.com/api/v1/waitlist

The page includes a 20 second request timeout so users do not remain on `Joining...` indefinitely if the API is unavailable or waking from a Render free tier sleep state.

Before public launch, have the legal pages reviewed by qualified Nigerian counsel. The policy text is written for the current prelaunch website and does not represent that future marketplace payment or transaction features are already live.

Official regulatory references used during drafting:
Nigeria Data Protection Commission: https://ndpc.gov.ng/
Federal Competition and Consumer Protection Commission: https://fccpc.gov.ng/
